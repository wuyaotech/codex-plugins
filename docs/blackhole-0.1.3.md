# Nebulix Studio 0.1.3 黑洞接入发布记录

日期：2026-10-13。团队源以 `main` 分支为安装入口；本版合并到该分支后，具备仓库读取权限的同事即可按首页流程更新。插件源码版本为 0.1.3，本记录不代表用户已安装，也不代替平台部署和试点验收。

本版增加黑洞接入 Skill 参考及 PM 提示词，保留 0.1.2 的本地前端/云端 dev 联调流程。参考包含服务端资源配置、浏览器直连边界、私有受鉴权图片待验证范围，以及上游 403 的独立错误码。MCP dev 地址与市场索引不变，不内嵌令牌或新增权限。

## 配套版本

- 插件源码：0.1.3。
- 开发包：starter 1.2.0，文档 `docs/blackhole.md`、前端 runtime 适配器/公开类型、双端可选示例。
- 前端运行态：runtime version `1`、engineBh capability version `1`；真实 Studio 页面 provider 与宿主 SDK。
- 后端运行态：项目请求的 `ctx.engineBh.version=1`；示例后端经 dev artifact 激活后执行。

## 发布顺序

1. 平台维护者部署并验证兼容的平台 Service/Web 能力及 starter。
2. 检查插件变更、实际 dev 地址和兼容说明，合并/发布本仓团队版本。
3. PM 从既有团队源更新，核验安装版本、启用状态，并在新会话加载黑洞参考。
4. PM 使用本人授权的模块与项目验证真实场景、后端查询、第二次修改和旧宿主提示。

更新不覆盖模块源码或 vendored SDK；旧模块从新 starter 比较合并。插件发布权限与业务模块发布权限分别验证。
