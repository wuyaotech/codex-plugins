# H5 上传链路说明 0.1.8

插件0.1.8是发布说明补丁，starter0.3.1与SDK0.1.0保持。0.1.7已发布后补充本机链路经验，避免覆盖同版本分发。

平台实际使用相同208,027字节压缩ZIP与票据，curl --http1.1、空Expect头、--limit-rate16k、--max-time120在约12.7秒完成PUT并返回200；不节流的大请求在本机链路会reset/timeout。此处仅说明上传传输，不代表整站已激活。

技能reference将限速列为遇同类症状的可选排查项：先回读上传/产物状态，再使用仍有效的同一票据和同一字节重试，保留要求的请求头，不输出签名URL，不吞异常。其他客户不强制16k；PUT成功后仍需complete、预检、执行、状态与站点回读。

本补丁无代码或协议变更，继续以0.1.7的48文件receipt、独立构建与ZIP CRC结果为工具验证基础；插件结构和skill校验另行通过。平台development激活与回退仍由本轮回执记录。
